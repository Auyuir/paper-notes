# FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness

## 论文信息

| 属性 | 值 |
|------|-----|
| 标题 | FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness |
| 作者 | Tri Dao, Daniel Y. Fu, Stefano Ermon, Atri Rudra, Christopher Ré |
| 会议/期刊 | NeurIPS |
| 年份 | 2022 |

## 一句话总结

> 提出FlashAttention——一种IO-aware精确注意力算法，通过分块tiling、在线softmax和反向重计算，避免物化N×N注意力矩阵，将显存从二次降为线性，注意力计算最高加速7.6×。

## 核心问题

- Transformer自注意力在高序列长度下显存和耗时呈二次增长，成为长序列处理的瓶颈
- 已有的近似注意力方法虽然降低了复杂度，但牺牲了模型质量且往往没有实际挂钟加速
- 现代GPU上计算速度远超显存带宽，Transformer核心瓶颈在IO而非计算

## 关键洞察 / 创新点

1. **IO-Aware算法设计**：利用GPU显存层次（HBM → SRAM），将注意力计算视为IO受限问题而非计算受限问题
2. **Tiling分块计算**：将Q、K、V分割成小块，逐块加载到SRAM计算，避免完整注意力矩阵在HBM中的读写
3. **Online Softmax**：通过维护running max和running sum，在分块场景下仍能正确计算softmax归一化
4. **反向重计算**：前向只存softmax归一化因子（O(N)），反向在SRAM中重计算注意力矩阵，避免存储O(N²)的中间结果
5. **CUDA Kernel Fusion**：单个CUDA kernel完成全部注意力操作，最小化kernel launch开销

## 技术细节

### 与硬件的关联

> FlashAttention利用GPU显存层次：HBM（大、慢）→ SRAM（小、快）。传统attention需要将QK^T的N×N矩阵写入HBM再读回，FlashAttention通过分块确保中间结果始终留在SRAM中，只将最终结果写回HBM。这利用了GPU SRAM带宽远高于HBM的特性。

### 关键公式

softmax分块计算需要维护两个统计量：

$$m(x) = \max_i x_i，\quad f(x) = [e^{x_1 - m(x)}, ..., e^{x_B - m(x)}]$$

分块合并时更新：

$$m_{new} = \max(m_{old}, m_{current})$$
$$f_{new} = [e^{m_{old} - m_{new}}f_{old}, e^{m_{current} - m_{new}}f_{current}]$$

## 对我的启发

- GPU编程的核心思维：不仅仅考虑FLOPs，更要考虑数据搬运（IO）
- Fuse everything you can — 减少kernel launch和中间数据的HBM读写
- Tiling是GPU编程的基本范式，几乎所有矩阵运算都可以从中受益
